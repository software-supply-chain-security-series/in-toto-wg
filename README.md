# in-toto Project Working Group

This is the Software Supply Chain Security Series working group that works to push standards for the [in-toto project working group](https://in-toto.io/).

Note that this working group consists of the same personnel as [the in-toto steering committee](https://github.com/in-toto/community/blob/main/STEERING-COMMITTEE.md).

Please refer all broader discussion about the standards, the standardization process, implementations of the project, adopters, and other concerns to the in-toto project.  You can find more information on the project website: https://in-toto.io/

Organizations who would like to support the Working Group are encouraged to join the [Software Supply Chain Security Series](https://join.sscss.io).
